GHAZI PARFUMERIE — PROJET HTML
===============================

OUVRIR DANS INTELLIJ IDEA

1. Décompressez le fichier ZIP.
2. Dans IntelliJ IDEA, choisissez File > Open.
3. Sélectionnez le dossier GHAZI-HTML-INTERACTIVE-CORRECTED.
4. Faites un clic droit sur index.html.
5. Choisissez Open In > Browser.

Le projet fonctionne en HTML pur. N'utilisez pas npm install.

STRUCTURE

- index.html : page principale
- assets/images/ghazi-hero.jpg : image principale
