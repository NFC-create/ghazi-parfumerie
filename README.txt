GHAZI PARFUMERIE — LANDING PAGE NFC
===================================

Projet HTML/CSS/JavaScript statique : aucune installation npm n'est nécessaire.

OUVRIR DANS INTELLIJ IDEA
1. Décompressez le fichier ZIP.
2. Ouvrez IntelliJ IDEA.
3. Cliquez sur File > Open et sélectionnez le dossier décompressé.
4. Dans le panneau du projet, faites un clic droit sur index.html.
5. Choisissez Open In > Browser.

OPTION TERMINAL POWERSHELL
Placez-vous dans le dossier décompressé, puis exécutez :
    Start-Process .\index.html

Pour un serveur local :
    python -m http.server 5500
Puis ouvrez : http://localhost:5500

Le site contient exactement deux écrans verticaux. Faites défiler vers le bas
pour passer de l'accueil à la page de contact.
